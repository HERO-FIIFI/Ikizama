## Priority Issues

1. **[P1] Broken trust and conversion links**
   - **Why it matters:** Placeholder GitHub/LinkedIn URLs and a missing CV fail exactly when a recruiter chooses to act.
   - **Fix:** Replace them with verified URLs and add `public/cv.pdf`; until then, hide or disable these actions.
   - **Suggested command:** `$impeccable harden`

2. **[P1] The Path promises more trajectory than its data currently provides**
   - **Why it matters:** Four 2025–26 projects and one current role read as a project recap, not yet as disciplines evolving over time.
   - **Fix:** Add only verified milestones—education, role transitions, first production system, entry into AI/automation—and state what each changed in Andy's practice.
   - **Suggested command:** `$impeccable clarify`

3. **[P2] Project previews visually homogenize different systems**
   - **Why it matters:** Repeating stacked-isometric diagrams weakens recall after the first project.
   - **Fix:** Keep one visual grammar but give AURA a retrieval flow, RADAR a test/evidence pipeline, AirSms an incident lifecycle, and DevBrain a repository-verification loop.
   - **Suggested command:** `$impeccable bolder`

4. **[P2] The middle repeats proof instead of advancing the story**
   - **Why it matters:** Work, Engineering, and The Path repeat the same systems and terminology, creating a long confidence plateau.
   - **Fix:** Make Work prove outcomes and architecture, Engineering explain principles and capability clusters, and Path show progression and synthesis.
   - **Suggested command:** `$impeccable distill`

5. **[P2] Orientation and mobile accessibility need a finishing pass**
   - **Why it matters:** Navigation has no active-section state, the mobile Menu target is small, and dialog triggers need clearer ARIA state relationships.
   - **Fix:** Add scroll-aware `aria-current`, 44px mobile targets, and `aria-haspopup`, `aria-expanded`, and `aria-controls` where appropriate.
   - **Suggested command:** `$impeccable audit`
